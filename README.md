# JO / Visual Noise

Static portfolio landing page recreated from the supplied visual reference.

## Run
Open `index.html` in a browser.

## Images
Put these files in `assets/`:
- `portrait.jpg`
- `project-01.jpg`

The layout is responsive and includes:
- Medieval / Crusader-inspired visual system
- red-black palette
- typography hierarchy
- framed sections
- project grid
- ticker strip
- contact section
- grain/noise overlay
- scroll reveal animation
- subtle mouse parallax
